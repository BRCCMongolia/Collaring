# BRCC Collaring — зэрлэг амьтан барих, хүзүүвчлэх бүртгэл

Биологийн Нөөцийг Хамгаалах Төвийн (BRCC) хээрийн апп. Утасны браузераас нээгээд нүүр дэлгэцэд нэмж апп шиг ашиглана. Интернэтгүй ажиллаж, сүлжээтэй болмогц Google Sheet рүү илгээнэ.

Төлөвлөлтийн баримт: [`docs/HANDOFF.md`](docs/HANDOFF.md), [`docs/app_butets_v2.md`](docs/app_butets_v2.md).

## Файлууд

| Файл | Юу вэ |
|---|---|
| `index.html` | Аппын хуудас, "Говь" өнгөний загвар |
| `app.js` | Аппын бүх код |
| `vendor/htm-preact.js` | Дэлгэц зурах жижиг сан (BRCC аппаас) |
| `vendor/admin.js` | Аймаг, сумын жагсаалт (BRCC аппаас) |

## Аппын бүтэц

**Судалгаа** (нэр, зүйл, баг + үүрэг, бүртгэгч) → **Бодгаль** → нэг том товчоор урагшилдаг цагийн шугам. Товч дарах бүрт цаг, GPS автоматаар бичигдэнэ.

1. **Хөөлт эхэллээ**: секундомер + GPS зай. CPORT, хээрийн удирдамж (6.4), JHA-гийн дагуу хязгаар нь 5 км эсвэл 10 минут. **8 мин / 4 км** дээр анхааруулах дохио, **10 мин / 5 км** дээр "ЗОГС" дохио (10 секунд тутам давтана). Буудалгүй зогсоох товчтой.
2. **Буудлаа**: хөөсөн хугацаа, зай, буудсан цэг.
3. **Буудсаны дараах хяналт**: *Унасан / Хэвтсэн / Ойртсон* товч.
4. **Малын эмчийн үзлэг**: биеийн ерөнхий байдал, шарх сорви, амин үзүүлэлт (амьсгал, зүрх, биеийн хэм, салст; заавал биш), тэмдэглэл → **OK** / **OK биш** (OK биш бол хүзүүвчлэхгүй суллана).
5. **Хүзүүвчлэх эхэллээ**: 3 минутын зорилтот таймер. Хүзүүвчний сүүлийн 3 оронг бичихэд (808) 161808 + IMEI гарна, ашигласан хүзүүвч тэмдэглэгдэнэ. Хүйс, нас (бага нас бол өсөлтийн тэмдэглэл), үржлийн байдал (эм бол), зан төрх, TRD соронз. Дээж: Цус / Арчдас / Баас / Үс / Бусад → `812-ЦУС-1` гэх мэт дугаар. Хүзүүвчний ба бодгалийн зураг.
6. **Хүзүүвчилж дууслаа**
7. **Хяналт эхэллээ**: *Босов / Явсан / Сүрэгтээ нийлсэн* товч.
8. **Хяналт дууслаа**: сэргэлт (Сайн / Дунд / Муу), тэмдэглэл.

- Бодгалийг **аль ч алхмаас** эхлүүлж болно ("Өөр алхмаас эхлэх").
- **↶ Буцаах** нь сүүлийн алхмыг буцаана. Цаг дээр дарж гараар засна.
- Аймаг, сум, газрын нэр, амьдрах орчин, агаарын хэм нь дараагийн бодгальд хуулагдана. Агаарын хэм 5–20 °C-ээс гадуур бол анхааруулна.
- Бодгалиуд судалгаан дотроо *аймаг › сум › газар*-аар бүлэглэгдэнэ.
- Устгасан судалгаа, бодгаль хогийн саванд 30 хоног хадгалагдана.
- **Excel татах**: Бодгаль, Амин үзүүлэлт, Дээж, Хөөлтийн зам хуудастай. Тохиргоонд нөөц файл татах / сэргээх.
- Хязгаар, босгуудыг ⚙ Тохиргоонд өөрчилж болно.

**GPS үсрэлт шүүх:** нарийвчлал 25 м-ээс муу цэг, 120 км/ц-ээс хурдан үсрэлт, нарийвчлалаас бага хөдөлгөөнийг хасаж, сүүлийн 3 цэгийн дунджаар зөөлрүүлж зай тооцно. Хээрт машинаар туршаад босгыг тааруулна.

## 1. Байршуулах (GitHub Pages)

Репоны **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, хавтас **/ (root)** → **Save**. Хэдэн минутын дараа апп `https://brccmongolia.github.io/collaring/` дээр гарна.

Шинэ хувилбар гаргахдаа `sw.js` доторх `VERSION`-ийг өөрчилнө, тэгвэл утаснууд шинэчлэгдэнэ.

## 2. Утсанд суулгах

**iPhone (Safari):** линкийг нээгээд **Хуваалцах → Add to Home Screen**. **Android (Chrome):** **⋮ → Add to Home screen / Install app**.
Нэг удаа сүлжээтэй нээсний дараа сүлжээгүй ажиллана. Аппыг заавал нүүр дэлгэцийн дүрсээр нээнэ. Хөөлтийн үед дэлгэцийг асаалттай, аппыг нээлттэй байлгана.

## 3. Google Sheet холбох (нэг удаа)

1. Шинэ Google Sheet үүсгэнэ (ж: `BRCC Collaring 2026`).
2. **Extensions → Apps Script**, доторх кодыг устгаад `apps-script.gs`-ийг бүхэлд нь буулгаж хадгална.
3. **Deploy → New deployment** → Web app, Execute as: **Me**, Who has access: **Anyone** → Deploy, зөвшөөрөл олгоно.
4. Гарсан `/exec` холбоосыг утас бүрийн аппын **⚙ Тохиргоо → Apps Script холбоос**-д буулгана.

Хуудсууд автоматаар үүснэ: **Бодгаль** (бодгаль нэг мөр, id-аар шинэчлэгдэнэ), **Судалгаа**, **Хөөлтийн зам**, **Зураг** (Drive дахь "BRCC Collaring зураг" хавтас руу холбоос).

## Дараагийн хувилбарт

- Хоёр утасны хооронд QR-оор бодгаль дамжуулах, өдрийн төгсгөлд солилцож "Нэгтгэх үү?" гэж санал болгох.
- Сумыг GPS-ээс автоматаар тогтоох (одоогоор жагсаалтаас сонгоно).
