# BRCC Collaring: төлөвлөлтийн тойм (2026-11-04)

Энэ файл нь аппын хэлэлцүүлгийг өөр төсөл рүү шилжүүлэх зорилготой. Код хараахан бичигдээгүй.

## Файлууд
- `app_butets_v2.md`: одоогийн бүтэц (гол баримт)
- `app_butets_sanal_v0.md`: анхны өргөн санал (лавлагаа)
- `collars_iridium.csv`: 30 хүзүүвч (161808–161837) ба Iridium IMEI, хэрэглэгчийн имэйлээс хуулсан
- `old_paper_datasheet_2025.png`: хуучин цаасан маягт (Gazelle & Argali Collar Project 2025)
- Загварын зураг (6 дэлгэц): https://claude.ai/artifact/R72W96JjD65CqNYdheBaXF

## Тохирсон шийдвэрүүд
- Веб апп (PWA), Android ба iPhone, интернэтгүй ажиллана. Нэр **BRCC Collaring**, BRCC лого.
- Суурь: BRCCMongolia/BRCC аппын кодыг (offline хадгалалт, Apps Script → Google Sheet upsert, хогийн сав, GPS замнал, дохио, Excel/KMZ) дахин ашиглана.
- Бүтэц: Судалгаа (нэр, зүйл, баг + үүрэг, бүртгэгч) → Бодгаль → товчоор урагшилдаг цагийн шугам:
  Хөөлт эхэллээ → Буудлаа → Буудсаны дараах хяналт → Малын эмчийн үзлэг (OK / OK биш = хүзүүвчлэхгүй суллана) → Хүзүүвчлэх эхэллээ → Хүзүүвчилж дууслаа → Хяналт эхэллээ → Хяналт дууслаа. Цаг, GPS, хугацаа автомат.
- Хөөлт: секундомер, GPS зай (үсрэлт шүүх: нарийвчлал, хурдны босго, зөөлрүүлэлт), хугацааны дохио.
- Буугаар буудна: эм, тун бүртгэхгүй. Морфологийн хэмжилт одоогоор байхгүй. "Өсөлтийг тооцсон эсэх" тийм/үгүй талбар хасагдсан.
- Хүзүүвч: сүүлийн 3 оронг бичихэд (808) нөөцөөс 161808 + IMEI автоматаар. Ашигласан хүзүүвч жагсаалтаас хасагдана.
- Дээж: Цус / Арчдас / Баас / бусад товч → `808-ЦУС-1` гэх мэт автомат дугаар. Хүзүүвчний ба бодгалийн зураг.
- Аймаг, сум: апп дотор сумын хилээр GPS-ээс автоматаар тогтооно. Газрын нэрийг гараар бичнэ, дараагийн бодгалиудад хадгалагдана. Бодгалиуд аймаг → сум → газраар бүлэглэгдэнэ (дэд фолдер биш). Энэ улиралд 2 аймаг, ~5 сум.
- Хоёр машин: амьтан дээр уулзвал QR-оор бодгалийг дамжуулна. Уулзаагүй бол өдрийн төгсгөлд бүх өгөгдлөө QR-оор солилцож, ижил бодгалийг "Нэгтгэх үү?" гэж санал болгоно. Бодгалийг аль ч алхмаас эхлүүлж болно.
- Өгөгдөл Google Sheet рүү, зураг Google Drive руу автоматаар. Судалгаа, бодгалийг устгах товч (хогийн сав).
- Байршуулалт: энэ репо, GitHub Pages → `brccmongolia.github.io/Collaring/`. Claude GitHub апп энэ репо дээр суусан (push ажиллана).

## Нээлттэй асуултууд
1. Өнгөний хувилбар: хуучин аппын ногооноос өөр байх. Санал: **"Говь"** (элсний шаргал дэвсгэр, тоосгон улбар шар товч) эсвэл **"Шөнийн тал"** (гүн хөх-ногоон дэвсгэр, тод шар товч).
2. Загварын зургийн талаарх санал (хэрэглэгч хараахан батлаагүй).
3. Хулан хүзүүвчлэх ажлын SOW / гэрээ байвал талбаруудыг тааруулах.
4. Хөөлтийн дохионы минут (жишээ 3, 5 мин) тодорхойгүй.
