# Хулан хүзүүвчлэх ажлын мэдээлэл цуглуулах апп: бүтцийн санал (v0, ярилцах зориулалттай)

> Энэ бол эхний санал. Код бичихээс өмнө хамтдаа засаж батална.

## 1. Үндсэн зарчим
- **Интернэтгүй ажиллана (offline-first).** Говьд сүлжээ байхгүй тул бүх мэдээлэл утсан дээр хадгалагдаж, хот орж ирээд экспортлох/синк хийнэ.
- **Нэг амьтан = нэг "барилтын бүртгэл" (capture event).** Бүх дэлгэц тэр бүртгэлд холбогдоно.
- **Цаг автоматаар тэмдэглэнэ.** Товч дарахад цаг нь өөрөө бичигдэнэ (тарилга хийсэн, хэвтсэн, сэргээх тариа гэх мэт). Бээлийтэй, нартай үед ч дарахад амар том товчнууд.
- **Хэдэн хүн зэрэг бөглөнө.** Жишээ нь мал эмч тариа/амин үзүүлэлт, нөгөө хүн хэмжилт, гурав дахь нь дээж.
- **Экспорт:** CSV/Excel (R-д шууд), GPS цэгүүд KML/GPX (ArcGIS, Google Earth), зургууд.

## 2. Дэлгэцүүд (screens)

### A. Төсөл / экспедиц тохиргоо (нэг удаа)
- Төслийн нэр, улирал, бүс нутаг (жишээ: Говь-Гурвансайхан, Их нарт)
- Багийн гишүүд ба үүрэг (баг ахлагч, мал эмч, нисгэгч/жолооч, хэмжигч, зурагчин)
- Эмийн жагсаалт ба концентраци (мг/мл) урьдчилан оруулна → тун тооцоолоход ашиглана
- Хүзүүвчийн нөөц: серийн дугаар, үйлдвэрлэгч (Vectronic, Lotek, Followit...), загвар, VHF давтамж, Iridium/GSM ID, хэмжээ, жин, drop-off тохиргоо

### B. Шинэ барилт эхлүүлэх
- Огноо, эхлэх цаг (автомат)
- GPS байршил (утасны GPS автомат + гараар засах), өндөр
- Аргачлал: машинаас буудах / нисдэг тэргээс / бусад; зай (м)
- Цаг агаар: агаарын хэм, салхи, үүл
- Сүргийн хэмжээ, бүтэц (эр/эм/унага тоо), амьтныг сүргээс ялгасан эсэх
- Хөөлтийн хугацаа (минут) → stress үнэлэхэд чухал

### C. Мэдээ алдуулалт (immobilization)
- Тусгал (dart): төрөл, хэмжээ, тусгасан цаг, оносон байрлал (гуя/мөр...), онох оролдлогын тоо
- Эм бүрээр: нэр, тун (мг), эзлэхүүн (мл) → **тооцоолсон жин-д ногдох тун (мг/кг) автоматаар**
- Цаг хэмжээ: тусгасан → анхны шинж тэмдэг → хэвтсэн (induction time автомат тооцно)
- Нэмэлт тун хийсэн эсэх, цаг, хэмжээ
- Сэргээх тариа (antagonist): нэр, тун, зам (IV/IM), цаг → босох хүртэлх хугацаа автомат
- Хүндрэл: бөөлжих, чичрэх, амьсгал зогсох гэх мэт сонголт + тэмдэглэл

### D. Амин үзүүлэлтийн хяналт (5 минут тутам)
- Таймер 5 минут тутам дуугарч сануулна
- Биеийн хэм (°C), зүрхний цохилт, амьсгалын тоо, SpO2 (pulse oximeter байвал), нүдний рефлекс, булчингийн чангарал
- **Анхааруулга:** хэм 40°C-с дээш, SpO2 90%-с доош гэх мэт босго давбал улаан өнгөөр анхааруулна (босгыг мал эмчтэй тохирно)
- Хөргөсөн, хүчилтөрөгч өгсөн гэх мэт арга хэмжээ + цаг

### E. Биометр (хэмжилт)
- Хүйс, насны ангилал (унага / залуу / насанд хүрсэн), шүдээр нас тогтоох
- Биеийн байдлын оноо (body condition score 1–5)
- Жин (жинлэсэн эсвэл тооцоолсон, аль нь гэдгийг заана)
- Хэмжээ: биеийн урт, мөрний өндөр, цээжний тойрог, хүзүүний тойрог (хүзүүвчинд чухал), чихний урт, сүүлний урт, туурай
- Жирэмслэлт / хөхүүл эсэх (эм бол)
- Шарх, шимэгч, сорви, бусад онцлог

### F. Хүзүүвч ба тэмдэг
- Нөөцөөс хүзүүвч сонгоно (серийн дугаар, давтамж автомат бөглөгдөнө)
- Зүүсэн цаг, хүзүүвч ба хүзүүний хоорондох зай (хуруугаар/см)
- Идэвхжүүлсэн эсэх, анхны дохио шалгасан эсэх
- Чихний шошго / микрочип дугаар, амьтны ID (жишээ: KH-2026-01)

### G. Дээж
- Төрлөөр нь сонгох: цус (EDTA, serum), үс, арьс (биопси), баас, шимэгч, арчдас (swab)
- Дээж бүрд **автомат дугаар / QR шошго** (жишээ: KH-2026-01-BL-1)
- Хэмжээ, хадгалсан арга (мөс, этанол, хуурай), хүлээн авах лаборатори
- Хэн авсан, цаг

### H. Зураг
- Заавал авах зургийн жагсаалт: бүх бие (хажуу тал 2), толгой, шүд, хүзүүвч зүүсэн байдал, онцлог тэмдэг
- Зураг бүр амьтны ID-тай автоматаар холбогдоно

### I. Суллалт
- Суллах цаг, байршил, босох хүртэлх хугацаа
- Сэргэлтийн чанар (сайн / дунд / муу), сүрэгтээ нийлсэн эсэх
- Багийн ерөнхий тэмдэглэл, гарын үсэг/хянасан хүн

### J. Тойм ба экспорт
- Бүх барилтын жагсаалт, газрын зураг дээр цэгүүд
- Дутуу бөглөсөн талбарыг улаанаар харуулна
- CSV/Excel, KML, зураг, PDF тайлан (нэг амьтанд нэг хуудас) экспорт

## 3. Платформын сонголт (ярилцах)
| Сонголт | Давуу тал | Сул тал |
|---|---|---|
| **A. KoboToolbox / ODK форм** | Хурдан, үнэгүй, offline сайн, зэрлэг амьтны судалгаанд түгээмэл, сервер бэлэн | Таймер, тун тооцоолол, хүзүүвчийн нөөц зэрэг нарийн функц хязгаартай |
| **B. Веб апп (PWA), утсанд суулгадаг** | Бүх функцийг хүссэнээрээ, Android/iPhone/таблет дээр нэг код, offline ажиллана | Хийх хугацаа урт, туршилт шаардлагатай |
| **C. Хосолсон**: эхлээд Kobo форм, дараа нь PWA | Энэ улиралд ашиглаж эхэлнэ, туршлагаар сайжруулна | Хоёр удаа ажил |

Миний анхны зөвлөмж: **B (PWA)**, учир нь 5 минутын таймер, автомат тун тооцоолол, анхааруулга нь энэ аппыг энгийн формоос ялгах гол зүйл. Гэхдээ хугацаа давчуу бол C.
